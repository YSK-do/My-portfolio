勤怠・給与計算システム

画像をクリックしてデモを開く（新しいタブ）

勤務時間を入力すると、実働時間・残業時間・給与概算を自動計算し、 月単位で確認できるWebアプリです。

JavaとSpring Bootで制作し、勤務時間の登録、月間集計、CSV保存に対応しています。

使用技術
  • Java 17
  • Spring Boot
  • JavaScript
  • HTML
  • CSS
  • Maven
  • JUnit
  • Render

工夫した点

  • 前職で感じた課題をもとに、働いた時間と給与を確認しやすい形にしました。
  • PC操作が苦手な方でも迷いにくい、シンプルな入力画面を意識しました。
  • 今月・前月を選んで登録でき、同じ日付・氏名のデータは上書きできるようにしました。
  • 計算処理やCSV保存、月間集計にJUnitテストを追加しました。

TimeCard Test Data Generator

勤怠・給与計算システムのテストを簡単に行うために、 勤務データを自動生成するPythonツールです。

1か月分または1年分の勤怠データをCSV形式で生成できるため、 大量のデータを手入力せずに月間集計や過去データ表示を確認できます。

使用技術
  • Python 3.10
  • unittest
  • CSV
  • GitHub Actions

作成した理由

  • 勤怠データを毎回手入力する手間を減らし、テストを簡単に行えるようにするためです。
  • Java版と同じCSV形式と給与計算式を使い、実際の動作に近いデータを準備できるようにしました。
  • 同じ条件のデータを再現できるようにし、不具合の確認や修正後の再テストを行いやすくしました。

主な機能

  • 1か月分または1年分の勤務データを生成できます。
  • 氏名、時給、出勤率、土日の扱い、文字コードなどを指定できます。
  • 乱数の種を指定し、同じテストデータを再生成できます。
  • 給与計算やCSV形式をunittestで自動テストしています。
