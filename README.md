# My Portfolio

HTML・CSSの学習成果と、Java・Spring Bootで開発したWebアプリケーションを紹介するポートフォリオです。

前職の事務経験で感じた課題を題材に、利用者が迷いにくい画面と、勤務時間・給与を自分で確認できる仕組みを制作しました。

## 制作物

### 勤怠管理・給与計算システム

時給制で働く方が、毎日の勤務時間を記録し、実働時間・残業時間・給与概算を月単位で確認できるWebアプリです。

Javaの基本処理を学ぶためのCLI版から開発を始め、実際にブラウザで使いやすいよう、Spring Bootを使用したWeb版へ発展させました。現在はWeb版を主な成果物としています。

- **公開サイト**：[勤怠管理・給与計算システムを開く](https://timecard-payroll-system.onrender.com)
- **GitHub**：[TimeCard-Payroll-System](https://github.com/YSK-do/TimeCard-Payroll-System)

> **デモ環境のご利用上の注意**  
> 学習用のデモ環境です。実在する氏名や個人情報は入力しないでください。データベースやログイン機能は使用しておらず、保存されたデータは他の利用者と共有される可能性があります。

> Renderの無料プランを使用しているため、初回表示に時間がかかる場合があります。

#### 開発の背景

前職で派遣社員として勤務していた際、残業時間の管理が曖昧で、給与の未払いを経験しました。

この経験から、働いた時間と給与を自分でも記録し、勤務先の勤怠データと比較しやすくすることを目的に開発しました。毎日使用することを想定し、PC操作が得意でない方でも迷いにくい画面を目指しています。

#### Web版でできること

- 氏名・時給・1日の所定労働時間・休憩時間の保存
- 時給を1円単位で自由入力
- 所定労働時間を4時間から8時間まで30分刻みで選択
- 出勤時刻・退勤時刻・勤務日の登録
- 実働時間・所定労働時間を超えた時間・給与概算の自動計算
- 同じ氏名・勤務日の記録を再登録した場合の上書き
- 登録後の月間集計・カレンダー・日別詳細の即時更新
- 月間カレンダーによる登録済み勤務日の確認と日付選択
- 選択した日の出退勤時刻・実働時間・残業時間・給与内訳の表示
- 勤務日数・実働時間・残業時間・基本給与・残業手当・支給金額の月間集計
- 年月指定と前月・次月ボタンによる過去履歴の表示
- 過去月の閲覧専用表示と、必要に応じた編集許可
- 選択月の勤怠データのCSV出力
- 休憩を取れたか振り返る任意項目と表示設定
- 入力エラーの画面表示とJSON形式のAPIエラー応答

設定と勤怠記録は、サーバー側のCSVファイルに保存します。

#### 給与計算

現在のWeb版では、設定した所定労働時間を超えた分を残業時間として表示し、25%分を追加して計算します。

```text
実働時間 ＝ 退勤時刻 − 出勤時刻 − 設定した休憩時間
基本給与 ＝ 実働時間 × 時給
残業手当 ＝ 所定労働時間を超えた時間 × 時給 × 25%
支給金額 ＝ 基本給与 ＋ 残業手当
```

金額は1分単位で計算し、1円未満を切り捨てます。

> この計算は学習用に単純化しています。法定時間外労働、深夜・休日労働などを含む正式な給与計算には対応していません。

#### 課題解決のために工夫した点

- 前職で感じた「勤務時間と給与を自分で確認しにくい」という課題を、日別記録と月間集計で確認できる形にしました。
- CLI版をそのまま画面化するのではなく、毎日使う場面を考えて入力方法と画面構成を作り直しました。
- 月初に前月分を登録できるよう、今月・前月を選択できる入力方法にしました。
- カレンダーから勤務日を選び、登録内容と給与内訳をすぐに確認できるようにしました。
- 過去の記録を誤って変更しにくいよう、過去月は初期状態で閲覧専用にしました。
- 登録後に集計・カレンダー・選択日の内容を再読み込みし、画面と保存データのずれを防ぎました。
- Controller・Service・Repository・Domainに役割を分け、処理を確認・テストしやすい構成にしました。
- 給与計算、設定の保存と読み込み、勤怠CSVの保存と上書き、月間集計にJUnitテストを追加しました。

詳しい仕様、起動方法、API、テスト内容については、[TimeCard-Payroll-SystemのREADME](https://github.com/YSK-do/TimeCard-Payroll-System#readme)をご覧ください。

## 開発を通して学んだこと

最初は何から手を付けるべきか分からなかったため、機能を小さく分け、入力・計算・保存・表示の順に実装しました。

CLI版ではJavaの基本文法、クラス分割、CSVの読み書きを学びました。その後、Web版へ発展させる中で、Spring BootによるREST API、Controller・Service・Repositoryの役割分担、JavaScriptからのAPI通信、月間カレンダーや履歴画面の状態管理、JUnitによる自動テストを学びました。

機能追加だけでなく、実際の利用場面を想定して入力方法や表示内容を見直し、問題を小さく分けて改善することの重要性を学びました。

## 現在の制限

- 個人利用を想定しており、複数ユーザーのアカウント管理には未対応
- データベースではなくCSVファイルへ保存
- 日をまたぐ勤務には未対応
- 法定時間外労働、深夜労働、休日労働、有給休暇などの正式な勤怠・割増計算には未対応
- 税金、社会保険料、交通費などの控除・手当には未対応
- 休憩を取れたかの回答は振り返り用で、給与計算やCSV保存には使用しない
- CLI版とWeb版は別の処理・CSV形式で動作
