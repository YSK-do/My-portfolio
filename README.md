## 制作物

### 勤怠管理・給与計算システム

Javaの学習を目的に開発した、個人向けの勤怠管理・給与概算システムです。  
ブラウザから勤怠を登録し、実働時間・残業時間・給与概算を自動計算できます。

- **公開サイト**：[勤怠管理・給与計算システムを開く](https://timecard-payroll-system.onrender.com)
- **GitHub**：[TimeCard-Payroll-System](https://github.com/YSK-do/TimeCard-Payroll-System)

> **ご利用上の注意**  
> 学習用のデモ環境です。実在する氏名や個人情報は入力しないでください。保存されたデータは他の利用者と共有される可能性があります。

> Renderの無料プランを使用しているため、初回表示に時間がかかる場合があります。

#### 開発の背景

前職で勤怠と給与の確認に課題を感じた経験から、自分で勤務時間と給与概算を確認できるアプリを開発しました。

毎日使用することを想定し、PC操作が苦手な方でも迷いにくい、シンプルなシステムを目指しています。

#### 主な機能

- 勤務日・出勤時刻・退勤時刻の登録
- 氏名・時給・標準労働時間・休憩時間の設定
- 実働時間・残業時間の自動計算
- 基本給与・残業手当・支給金額の自動計算
- 月ごとの勤務日数・勤務時間・給与の集計
- CSV形式でのデータ保存
- 同じ勤務日・氏名の記録を上書き
- 入力内容の確認画面と登録結果の表示

詳しい仕様、起動方法、テスト内容については、[TimeCard-Payroll-SystemのREADME](https://github.com/YSK-do/TimeCard-Payroll-System#readme)をご覧ください。

## 使用技術

| 分類 | 技術 | 使用内容 |
| --- | --- | --- |
| 言語 | Java 17 | 勤怠・給与計算、Web API、CSV保存 |
| 言語 | JavaScript | 画面操作、Web APIとの通信 |
| フレームワーク | Spring Boot 4.1.0 | WebアプリケーションとREST APIの構築 |
| フロントエンド | HTML5 / CSS3 | ポートフォリオと勤怠入力画面の作成 |
| ビルド | Maven | Javaプロジェクトのビルドと依存関係管理 |
| テスト | JUnit | 給与計算、設定、CSV保存、月間集計の自動テスト |
| データ保存 | CSV | 基本設定と勤怠記録の保存 |
| バージョン管理 | Git / GitHub | ソースコードと変更履歴の管理 |
| デプロイ | Render | Webアプリケーションの公開 |

## 開発を通して学んだこと

最初は何から手を付けるべきか分からなかったため、機能を小さく分け、入力・計算・保存の順に実装しました。

開発を進める中で、Javaの基本文法だけでなく、クラスの役割分担、Spring BootによるWeb API、CSVへのデータ保存、JUnitを使った自動テスト、GitHubによるバージョン管理を学びました。

## 今後の課題

- CLI版とWeb版で重複している給与計算処理の統合
- Controller・Serviceのテスト拡充
- CSV保存からデータベース保存への移行
- 日をまたぐ勤務や深夜労働など、より複雑な勤務条件への対応

## 注意事項

勤怠管理・給与計算システムは、JavaとSpring Bootの学習を目的とした個人開発作品です。

実際の給与計算や勤怠管理に使用する場合は、勤務先の就業規則や最新の法令に合わせた確認・調整が必要です。
